# 🌙 MoonlightCommittee

**달빛 인민 위원회 — KakaoTalk PC 자동화 프로그램**

## 기능
- Windows GUI 프로그램
- 카카오톡 PC 실행 보조
- 대상 채팅방 이름 설정
- 가상국가 명령어 응답 테스트
- 클립보드 기반 카카오톡 응답 전송
- GitHub Actions에서 Windows x64 EXE 자동 빌드

## 현재 지원 명령어
- `>도움말`
- `>가입`
- `>내정보`
- `>잔액`
- `>공장`
- `>주식`
- `>뉴스`

## EXE 받기
GitHub의 **Actions → Build Windows EXE** 실행이 완료되면 **Artifacts**에서
`MoonlightCommittee-Windows` ZIP을 다운로드할 수 있습니다.

## 실행 방법
1. Windows에서 EXE 실행
2. 카카오톡 PC를 로그인
3. 대상 채팅방을 열기
4. 프로그램에서 **봇 시작**
5. 필요하면 명령어를 입력하고 **카톡에 보내기** 사용

## 주의
이 프로그램은 카카오톡 공식 봇 API가 아니라 Windows PC UI 자동화를 사용하는 베타 프로젝트입니다.
카카오톡 업데이트에 따라 자동화 동작이 변경될 수 있습니다.
